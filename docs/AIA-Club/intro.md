### Use the 5-Component Framework to write a complete prompt for the AI

- Role: Who should the AI be?
- Context: What is the background/situation?
- Task: What should the AI do?
- Output: How should the result look? Give an example.
- Constraints: Any limits or requirements?

#### Beispiel
- Role: Du bist ein freundlicher Deutschlehrer für Anfänger.
- Context: Ein Lernender möchte einfache deutsche Sätze verstehen.
- Task: Gib drei sehr einfache deutsche Beispielsätze und erkläre sie kurz.
- Output: Verwende eine Liste. Unter jedem Satz soll eine kurze Erklärung stehen.
- Constraints: Keine Fachbegriffe, alles sehr leicht verständlich, maximal drei Sätze.

#### Beispielausgabe
- „Ich habe Hunger.“ - Das bedeutet, dass du etwas essen möchtest.
- „Das Wetter ist schön.“ - Du sagst damit, dass dir das Wetter gefällt.
- „Ich lerne Deutsch.“ - Das heißt, dass du gerade Deutsch übst.

### Step 6: Create a system and user message with AI for the ChatGPT Action configuration
**Role:** You are an expert at creating UGC Video Content Using Veo 3 (fast) for e-commerce brands 

**Context:** I work for a brand called Colgate, and I am trying to create social media content for my Instagram channel. I want UGC videos of my brand. Here is what will I provide as an Input: It will be from a Google Sheet where I will enter these details every time I want a new video
What kind of video I want to create? (messaging, actors, any other specifications)	Who is my target audience?	Product Image	Video Specifications
And I want ChatGPT to write a Video Script for me for 6 Sec videos on Veo 3. 
I am providing this input in Zapier. I want to create a no code Automation workflow

**Task:** I want ChatGPT to write a System Message and a User Message for me for this specific task. 

**User Message:** should have JSon formatting for the columns/headers in excel sheet which will be the Input for Open AI Conversation Node. Make sure the Json structure is formatted correctly.
System Message should have detailed instructions including examples of how I want my output.
Output Example: I want my scripts to focus on emotions, and the design of my tooth brush, how its different from regular ones, and focus on like emotional storytelling specific to that target example. 

**Constraints:** Just make sure its optimized for my Instagram account. 

User Message:
```
{
  "video_request": "{{Video idea}}",
  "target_audience": "{{Who is my target audience?}}",
  "product_image_url": "{{Product Image}}",
  "video_specifications": "{{Video Specifications}}",
  "additional_notes": "{{Any other specifications}}"
}
```
System Message:
```
You are an expert UGC video script writer specialized in ultra-short (6-second) 
vertical videos for Instagram, optimized for Veo 3 avatar-based generation. 
Brand: Colgate. Tone: emotive, friendly, trustworthy, product-focused. 
Constraints: total duration 6s, voiceover ≤ 12 words, aspect ratio 9:16, 
captions required, no profanity, avoid mentioning internal API keys or sensitive data.

Output requirements (respond exactly in the format below):
1) A JSON object named "video_script" with:
   - duration_seconds: number
   - aspect_ratio: "9:16"
   - scenes: array of scene objects with:
     - start: seconds (float)
     - end: seconds (float)
     - shot_description: short text
     - on_screen_text: short text (max 6 words)
     - voiceover: short sentence (≤12 words)
     - visual_instructions: concise directions for avatar, props, product placement
     - camera: e.g., "close-up", "mid", "push-in"
     - avatar_instructions: gender/age/skin-tone, expression, gesture, lip-sync: true
     - assets: { product_image_url, logo, bg_color }
     - music_suggestion: short note (mood, bpm)
     - sfx: optional
     - cta: final short call to action
   - captions: true

2) A short "human_readable_script" (max 6 lines) summarizing the scenes for production.

Example: provide one complete 6s script for Colgate as a sample. Do not include any secrets.
Return only the JSON and the human_readable_script, nothing else.
```
